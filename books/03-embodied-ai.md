## ○ 先补一级台阶：从「会动」到「把事情做成」

具身智能这几年很热，但同一个词下面常常混着好几件不同的事。先建立一个判断尺度——**看一个系统处在哪个阶段**：

- **会动**：机器人能完成预先编排的动作。跑步、跳舞、搬箱子，动作是写死或离线规划好的。
- **会做事**：机器人能理解任务并完成目标。给一句「把红色杯子放进抽屉」，它能自己找到杯子、拉开抽屉、完成放置。
- **持续把事情做成**：换一个物体、换一个房间、换一个任务，遇到意外还能调整。杯子滑了一下，它知道重新抓；抽屉卡住了，它知道换个角度。

今天具身智能的大部分进展与争论，都发生在从第二步走向第三步的路上。新模型层出不穷，但先判断一项工作处在哪个阶段，往往比记住模型叫什么名字更有用。

接下来你会反复遇到六个词，先各放一句话在这里，后文会逐个展开：

| 名词 | 一句话定位 | 在哪一节展开 |
|-|-|-|
| 模仿学习 | 从人类示范里学动作，多数系统的训练起点 | 2.1 |
| Diffusion Policy / Flow Matching | 生成式动作模型，解决「合理动作不止一种」的问题 | 2.1 |
| VLA | 视觉—语言—动作模型，把「看懂、听懂、行动」接在一起 | 2.2 |
| 世界模型 | 预测环境会怎样随动作变化，用于规划或表征学习 | 2.3 |
| 强化学习 | 用结果反馈持续优化策略 | 2.4 |
| Sim-to-Real | 仿真里训练、真机上用，中间有一道必须跨的差距 | 3.4 |

这份清单会沿这条主线走：先认识具身智能在解决什么问题，再看机器人怎样学会行动，然后看 Demo 走向真实应用时要过哪几道关卡，最后再看当下的路线之争与可选的进入路径。

## 一、先认识：具身智能到底在解决什么问题？

上一节给了「会动—会做事—持续把事情做成」这个尺度，这一章要问的是：具身智能和机器人学是不是同一件事。

**不是，但相互有重叠。** 机器人学覆盖的是一整套工程系统——本体结构、电机与驱动、传感器、控制回路、运动规划；具身智能关心的却是另一个问题：智能能不能、以及如何从与物理环境的持续交互中产生。前者是系统的视角，后者是智能的视角。

举一个卡在边界上的例子：一台纯遥控的机械臂，动作全部来自人，它本身是机器人学的成果，谈不上具身智能——但遥操作恰恰是具身智能采集示范数据的主要手段，研究的对象不是遥控本身，而是从这些数据里长出来的自主策略。另一边，一个在仿真里学会走路的策略没有实体，却属于具身智能的算法层。两者大面积交叉，但评判标准不同：机器人学看精度、稳定性、成本；具身智能看泛化、自主性、能否应对未见过的情形。

区分清楚之后，一个更直观的入口是看**智能体能否形成闭环**：

> 观察环境 → 理解任务 → 采取行动 → 接收反馈 → 根据变化继续行动

比如让机械臂把红色杯子放进抽屉。它要定位杯子和抽屉，理解「拿起—移动—放入」这个任务结构，生成一段动作，再根据杯子有没有滑动、抽屉是否打开等情况进行不断的修正。任何一环断掉，任务都会失败。

这也是具身智能与纯语言任务差别最大的地方。一个词生成得不好，下一句还有机会修正；但机械臂尽管只抓偏几厘米，杯子就可能摔碎在地上。**真实世界有噪声、有成本，有些动作不可逆**——这条约束会一路贯穿到后面每一章：为什么数据这么贵、为什么强化学习不敢随便探索、为什么评测不能只看成功率。

如果想先快速认识相关的常见名词，可以读 [《机器人具身智能三大流派：强化学习、VLA、World Model 到底在争什么？》](https://zhuanlan.zhihu.com/p/2013539588820444796) — 机器人技术笔记 · 🟢。不过要留意的是，「三大流派」只是方便入门的说法。现实中的系统往往同时使用模仿学习、VLA、世界模型和强化学习，并不是只能从中选一。

那么，具身智能该从哪里起步？这里有两种看法可以参考。

[《具身智能需要从 ImageNet 做起吗？》](https://zhuanlan.zhihu.com/p/1906157729292219201) — 许华哲Harry · 🟢 从大模型、机器人数据、二维与三维视觉、触觉、VLA、强化学习和评测标准等多个角度，解释了具身智能为什么既吸引人，又难以简单复刻语言模型的成功——差别在于，语言模型有互联网规模的数据，而具身数据必须靠物理交互采集。

南方科技大学助理教授、微分智飞联合创始人周博宇则提出另一种视角，[《具身智能：一场需要谦逊与耐心的科学远征》](https://zhuanlan.zhihu.com/p/1906835485990565345) — 周指导BoyuZhou · 🟢 强调具身智能并不会让控制理论、本体设计、材料、传感器和具体机器人任务失去价值。两篇文章观点并不完全相同，恰好能帮助理解：**具身智能目前仍是一个目标明确、路线尚未收敛的领域**。

## 二、再读懂：机器人怎样学会行动？

上一章把具身智能与机器人学的边界划清了，也给出了「运行时闭环」这个观察角度。这一章往机器里面看：机器人到底怎样学会行动。

把各种技术放回「学会做事」这条主线，可以沿着四个问题走：**怎样模仿人类动作，怎样听懂开放指令，怎样预判行动后果，以及怎样从成功和失败中继续改进。** 它们分别对应下面四节。

这四节不是四个并列的技术类别：模仿学习是训练范式，VLA 是模型形态，世界模型和强化学习各自负责不同环节。一个真实的系统里它们通常同时出现，读到后面会发现它们彼此间是反复缠绕的。

### 2.1 模仿学习：先跟着人类学

最直接的做法，是让人遥操作机器人完成任务，再让模型模仿这些示范。行为克隆（Behavior Cloning）可以理解为动作版的监督学习：给定当前状态，预测示范者的下一步动作。

它有两个绕不开的难点。

**第一，合理动作通常不止一种。** 同样是抓杯子，可以从左侧接近，也可以从右侧接近。用均方误差训练时，模型的最优输出是这些可能动作的条件均值——面对多峰分布，这个均值落在几种可能之间，哪条路都走不好。这不是数据不够，而是平方误差的最优解天然是均值，它表达不了「要么从左边抓、要么从右边抓」这种选择。

**第二，状态分布会漂移，误差随之被放大。** 模型在早期产生的小偏差会把它带到训练数据里没见过的状态，而在这个状态下它的预测更不准，于是偏得更远。这叫分布漂移（distribution shift）：训练时看到的是示范者走过的状态，测试时遇到的却是自己走偏之后的状态——小误差改变状态分布，漂移再放大小误差。

动作分块（Action Chunking）与生成式动作模型是应对这两个问题的主要手段。它们经常被一起用，边界也不是一刀切——ACT 一边做分块、一边用 CVAE 捕捉演示里的多种做法；Diffusion Policy 预测的也是一小段轨迹而不是单步。按侧重大致可以这样分：

- **动作分块**主要缓解累积误差。模型一次预测未来若干步的一小段动作而不是单步，有效决策次数下降，误差累积的机会随之减少。它顺带还处理了一个容易被忽略的问题：单帧观测不是马尔可夫状态——只看当前一帧，常常判断不出示范者正在做哪个动作，需要连续看一段才知道。
- **Diffusion Policy 与 Flow Matching** 侧重解决多峰分布。它们不去回归一个确定动作，而是对完整的动作分布建模，再从中采样，因此能同时表达「从左边抓」和「从右边抓」这两种可能。

这一节建议从这里开始：[《Diffusion Policy——基于扩散模型的机器人动作生成策略》](https://zhuanlan.zhihu.com/p/670555655) — 王建明 · 🟢，它把「为什么要用扩散模型生成动作」讲得最清楚，包括动作分布的多峰性、条件注入方式和训练细节。想先看一遍完整的入门资源清单，[《机器人学习（robot learning）领域如何入门？》](https://www.zhihu.com/question/627309352/answer/1996123281732941388) — Stan Fu · 🟢 这个回答把行为克隆、ACT、Diffusion Policy 和 Flow Matching 串了一遍，适合当作延伸阅读。

### 2.2 VLA：把「看懂、听懂、行动」接在一起

VLA（Vision-Language-Action）希望模型不仅能看图、理解语言，还能直接生成机器人动作。

过去，一个机器人任务往往要分别设计感知、规划和控制模块；VLA 则尝试借助大规模预训练，把视觉—语言知识与动作数据接起来。这样，「把香蕉放进篮子」和「把易碎物品收好」就有机会由同一个模型进行理解，而不是每个任务都需要重新写程序。

先澄清一个容易产生的误解：**VLA 和上一节的 Diffusion Policy 不是并列的两条路线。** 到了 π0、GR00T 这一代，两者其实合流了——模型整体是 VLA 的形态（接收图像和语言指令），而负责把意图变成具体动作的那一层，用的正是 flow matching 或扩散这样的生成式动作头。VLA 描述的是输入输出形态，Diffusion Policy / Flow Matching 描述的是动作端怎么生成。第五章把《Diffusion & Flow Matching》放进「想理解 VLA 与世界模型」这条路径，原因就在这里。

VLA 也不是把视觉语言模型的输出词表换成动作就结束了。**动作怎样表示**，是这一代模型必须做的一道选择：

|  | 离散动作 token | 连续动作（扩散 / flow 头） |
|-|-|-|
| 做法 | 把动作分箱成离散 token，复用 next-token prediction | 直接对连续动作分布建模，采样或积分出动作 |
| 好处 | 完全复用大模型的训练范式与基础设施 | 不损失精度，天然表达多峰动作分布 |
| 代价 | 分箱带来量化误差，粒度与精度难以两全；动作要逐 token 串行解码，维度一多延迟就上去了，所以实践中往往只预测单步、靠高频重规划补救 | 推理需要多次迭代，实时性压力大 |

除了动作表示，还有三件事同样棘手：不同机器人的关节、相机和控制频率并不相同，**跨本体数据怎样对齐**；文本和图像数据很多，带动作的数据却很贵；模型必须在有限时间内输出平滑、安全的动作，**推理又怎样加速**。

入门可以先读 [《【综述】具身智能中的 VLA 模型》](https://zhuanlan.zhihu.com/p/1951985172259004422) · 🟢，认识架构、数据、训练与评测的整体图景。想看清一个代表模型具体是怎么搭起来的，[《【VLA系列】万字深度解析 π0》](https://zhuanlan.zhihu.com/p/1907535034941965833) — AIming · 🔵 值得精读——π0 用的正是「预训练视觉语言模型 + flow matching 动作专家」的结构，前面那张对照表里它站在右边那一列，读它能把「连续动作头」这一支看得很具体。想理解行业当前在意的问题，推荐 [《具身 VLA 的 2025：从 Demo 到通用的距离》](https://zhuanlan.zhihu.com/p/1989799567177307432) — 林天威 · 🔵。

如果之后需要查某个模型或论文，可以把 [《【具身智能】机器人操作 VLA 模型论文整理》](https://zhuanlan.zhihu.com/p/7371838810) — Mayer Zhu · 🔵 当作索引，带着具体问题进行查阅。

### 2.3 世界模型：行动之前，先想一想后果

人拿起装满水的杯子时，会预判杯子倾斜后的结果；推门时，也会根据阻力调整力量。世界模型想让智能体获得类似的能力：学习环境会怎样随动作变化，再用这种预测帮助规划或训练。

它有两种差异很大的用法，混在一起看容易糊涂：

1. **作为动力学模型**：习得状态转移函数，在推理时「想象未来」来规划或做模型预测控制。这是最优控制与 model-based RL 共用的思路。
2. **作为表征预训练**：用大规模的视频参与训练，让模型学到更好的动作表征，推理时并不显式生成未来。

目前一个热议的问题正是二者的比较：世界模型的作用，主要来自推理时想象未来，还是来自训练时加入视频后学到了更好的表征？[《Fast-WAM：关于 WAM 核心能力来源的思考》](https://zhuanlan.zhihu.com/p/2018464228785275484) — 清华MARS Lab · 🔵 用控制变量实验讨论了这个问题。在它的测试范围内，**训练阶段的视频联合训练比推理阶段的显式生成未来更关键**。这个结论未必适用于所有模型，但分析问题的思路可以借用：最终分数涨了多少并不那么重要，需要追问的是这个分数到底由哪一部分贡献。

世界模型要学的也不只是「生成未来视频」。预测像素只是做法之一，要紧的是模型有没有抓住与行动有关的信息：物体是否可抓、接触后会怎样运动、某一步会不会让任务进入无法恢复的状态。想从一个更宏观的视角切入，可以读 [《世界模型（World Model）是不是机器人（具身智能）下一个「奇点时刻」？》](https://www.zhihu.com/question/1969460053296801225/answer/2031100230167426156) — 海抱 AI · 🔵。

### 2.4 强化学习：根据结果继续练

模仿学习回答「人通常怎么做」，强化学习更关心「怎样做结果更好」。机器人在环境中尝试，再根据成功率、稳定性、速度、能耗或安全性等反馈调整策略。

如果读过本系列第二册《RL 蓝宝书》，这里需要先校准一次直觉——**机器人 RL 与大模型 RL 的困难不在同一处**：

|  | 大模型 RL | 机器人 RL |
|-|-|-|
| 奖励 | 数学题有标准答案、代码有单元测试，可程序化判定 | 操作类任务多数只有「成功/失败」的二值信号，验证器要自己造（运控类是个例外，通常靠手工设计的稠密跟踪奖励） |
| 状态 | 离散 token，每一步的输出完整可见 | 连续、高维、部分可观测 |
| 探索 | 生成错了没有代价，可以大量采样 | 摔倒会损坏设备，安全约束是硬性的 |
| 成本单位 | GPU 卡时 | 仿真同样是 GPU 卡时，但仿真之外还得付出真机小时，设备会磨损 |

关于 PPO、GRPO、优势估计这些机制本身，可以回到第二册第二章，本册不重复。正因为样本贵、奖励稀疏、探索有代价，**今天更常见的路线并不是让机器人从零试错**，而是先用示范或预训练模型获得基础能力，再用离线或在线 RL 提高成功率、优化长程任务，或专门练习失败恢复。仿真、数据回放、安全约束和少量真机优化往往要一起使用。

运动控制方向可以先读 [《强化学习 & 四足 Quadruped》](https://zhuanlan.zhihu.com/p/570352241) — 白辰甲 · 🔵，建立四足 RL 的问题框架；再用 [《RL 做足式机器人运控的经典必读文章（带私货）》](https://zhuanlan.zhihu.com/p/29806809248) — Eric Liu · 🔵 铺开研究地图。[《机器人强化学习与关节 PD 控制》](https://zhuanlan.zhihu.com/p/1990213475369255309) — 白告 · 🟣 用一个具体问题解释：学习出来的策略最后怎样作用于真实关节。对「动作分块怎样接入 RL」感兴趣的话，可以继续看 [《很久没有见过这么优雅的 RL milestone 了：Reinforcement Learning with Action Chunking》](https://zhuanlan.zhihu.com/p/1927420187478570745) — 位德浩 · 🔵。

模仿学习提供了起点，VLA 连接了视觉、语言与动作，世界模型帮助理解环境的变化，强化学习则利用结果继续优化。在实际研究与工作中，它们通常互相组合，而不是彼此取代。

## 三、看现实：为什么精彩 Demo 还不等于可用？

上一章拆的是技术路线——机器人怎样学会行动。这一章换一个问题：学会了之后，为什么还没法用？

先分清两条链，否则很容易混：第一章那条「观察 → 理解 → 行动 → 反馈 → 继续行动」，描述的是**机器人运行时的一次循环**；这一章的「任务 → 数据 → 训练 → 执行 → 反馈 → 评测」，拆的是**把一个机器人系统做出来要过的关卡**。两处的「反馈」也不是一回事——前者是传感器回传的状态，后者是训练时用来更新模型的信号。

实验室里成功一次，与在真实环境中每天稳定工作，是两种截然不同的难度。这条链路至少有六道关卡。

### 3.1 数据贵，而且不一定通用

互联网有海量图文，却很少记录「某个机器人在某个状态下采取了什么动作」。真机数据要靠设备、场地和操作人员采集；不同机器人的结构和动作空间又不一样，一台机器的数据未必能直接给另一台使用。

所以大家在尝试遥操作、仿真、视频、跨本体和合成数据。要问的不只是「数据够不够多」，还包括：有没有失败和恢复过程？不同来源能否对齐？加入更多数据究竟带来迁移，还是稀释了动作信号？

这里可以和前两册对照一下：第二册《RL 蓝宝书》3.1 讲的是把真实工作合成成可训练任务，那里的数据能按需生成；本册面对的是真机动作轨迹，每一秒都要靠设备和人采集出来，成本结构完全不同。关于具身场景的特殊性，[《为什么「数据」被视为具身智能最大壁垒？》](https://www.zhihu.com/question/2072726754230101239/answer/2074508922489141235) — 于超 · 🟢 这篇回答讲得比较直接。

### 3.2 任务越长，小错误越容易滚大

抓一次固定物体可能只需几秒，整理房间或完成装配却要连续执行很多步。即使单步成功率高达 90%，连续二十步之后，在「每一步独立」的乐观假设下，成功率也只剩约 12%；而真实误差是前后相关的，实际操作起来往往还要更低。

现实环境不会在每一步执行后就自动复位。机器人要记得进度，及时发现自己走错，并决定是重试、换方案还是求助。这里有一个两难：**动作块太长，来不及响应环境变化；动作块太短，重规划太频繁，又带来延迟与轨迹拼接的抖动。**

[《如何看待目前 VLA 的具身智能技术？》](https://www.zhihu.com/question/1920708362489828723/answer/2034761425411945263) — 胡萝博 · 🔵 讨论动作块之间怎样保留历史；[《VLA 模型如何实现实时且平滑的动作控制？》](https://zhuanlan.zhihu.com/p/1986820879024427514) — CLEAR Lab · 🔵 则把延迟、轨迹拼接和快慢系统放进真实执行中解释。

### 3.3 「知道做什么」，不等于身体做得到

高层模型可以判断「抓住杯柄」，落到执行却要处理关节极限、摩擦、接触力、平衡和碰撞。对于人形机器人，走路、全身协调和双臂操作还会互相影响。

这也是端到端模型与分层系统仍然并存的原因。VLA 可以负责理解任务和给出目标，运动规划、MPC、WBC、PD 控制或学习型控制器则负责把目标变成高频、稳定的动作。

[《人形机器人运动控制 Know-How》](https://zhuanlan.zhihu.com/p/1993986785630499920) — Jagger · 🟣 从建模、MPC/WBC、强化学习一路讲到 Sim-to-Real。阅读它需要一些控制基础，建议按章节进行选读。

### 3.4 仿真很快，但现实总会多出几个变量

仿真可以并行生成大量轨迹，机器人能放心摔倒，也不会损坏设备。但摩擦、柔性接触、传感器噪声、时延和零件误差很难完全复现。仿真中表现得再完美，换到真机仍可能失败。

域随机化、系统辨识、教师—学生训练和真仿数据混合，都在缩小这道差距。其中**教师—学生训练这一支需要多说一句**：先让教师策略在仿真里用特权信息训练——精确地形、摩擦系数、接触力，教师看得见，真机上看不见，训练方式通常就是 RL；再让只能看到真机可观测输入的学生去模仿教师的动作。学生掌握的信息比教师少，所以这里的难点不是压缩模型，而是让学生从自己的观测历史里反推出它看不到的那些量。

顺着往下问：哪些物理细节必须精确建模，哪些变化可以让模型通过数据学会适应？关于这一方向站内系统性的中文内容不多，[《强化学习中 Sim-to-Real 方法综述：基础模型的进展、前景和挑战》](https://zhuanlan.zhihu.com/p/26730697492) — 黄浴 · 🔵 可作为进阶索引。

### 3.5 模型、算力和硬件要一起算账

大模型需要算力，控制回路却要求低延迟；传感器持续产生数据，机器人端的电池、散热和计算资源又有限。放在云端会遇到网络问题，全部放在本地又会受模型规模和功耗限制。

关于推理与部署的通用工程问题（批处理、KV Cache、显存、服务化），第一册《AI Infra 蓝宝书》第 2 章「推理系统」有展开。具身场景多出来的约束是**机器人本体这一端**，[《具身智能部署新思路——记中兴「云—边—端」部署架构》](https://zhuanlan.zhihu.com/p/2012569897574614338) — Duncan Zhang · 🔵 可以作为一种产业案例来读，但它不是标准答案。读的时候可以带着两个问题：不同频率、不同安全等级的能力应该放在哪里？断网或延迟上升时，机器人怎样安全降级？

硬件成本也不能忽略。采集数据要维护设备、标定传感器，真实训练会带来磨损，故障排查还横跨机械、电气、控制和软件。**稳定运行数百小时，往往比成功一次更难。**

### 3.6 评测不能只问「有没有成功过」

一个公开视频不会告诉我们：一共试了多少次？场景是否提前布置？换个物体还能不能做？失败后是否需要人工接管？

除了任务成功率，还需要看完成时间、人工干预率、对新场景的泛化、失败恢复能力和安全性。这些维度对应到第五章那组六问里的后两问——「测试时改变了什么」和「失败案例是什么」。

这一节没有推荐阅读：站内讲具身评测的内容不多，能找到的多是榜单发布和名次资讯，偏资讯而非方法论。想深入这个方向，可以从 RoboTwin、EBench 这类开源评测基座的文档与论文入手，看它们怎样定义任务、记录干预次数、公布失败案例。

## 四、看热议：现在的路线到底在争什么？

前三章说的是「这个领域怎么运作」，这一章说的是「还有哪些没定论」。四个议题的共同点是：都还没有共识，都可以被翻译成可检验的具体问题。

### 4.1 机器人能复制大模型的 Scaling 路线吗？

乐观的一方认为，只要统一数据格式，继续扩大模型和数据，机器人也会不断出现新能力。谨慎的一方则指出，具身数据贵、与本体强相关，物理交互的长尾也比文本难覆盖。

与其只争论「有没有 Scaling Law」，不如来看看三个具体问题：提升来自模型规模、数据数量还是数据多样性？能力能否迁移到新任务和新本体？资源继续增加后，真实成功率是否能够稳定上升？[《机器人也有 Scaling Law 吗？瓶颈究竟在模型、数据还是本体？》](https://www.zhihu.com/question/2072753441416242597/answer/2073354114088682507) — tomsheep · 🔵 正好沿这三个问题展开。

### 4.2 VLA、世界模型与 RL，是在争主路线吗？

三者解决的并不是同一个问题：VLA 连接视觉、语言和动作；世界模型关注环境变化与行动后果；RL 利用结果反馈优化策略。一个系统完全可以同时使用三者——第二章结尾已经点过这一点。

既然不互斥，该问的就不是「谁是主路线」，而是：在什么任务和数据条件下，哪一部分最关键？世界模型是否真的改善了决策，还是只是让表征更好？RL 的收益能否覆盖真机试错成本？VLA 的泛化是来自语义知识，还是训练数据里已经有相似轨迹？

这四问可以直接拿去套一篇新工作的技术报告：看它回答了哪几条，又跳过了哪几条。

### 4.3 端到端会取代传统分层系统吗？

端到端学习减少了人工设计接口，也可能让感知和动作围绕最终任务一起优化。但机器人同时存在毫秒级控制、秒级动作规划和更长时间的任务推理，很难用一个固定频率处理所有事情——这正是 3.3 那条约束的另一面：身体跟不上一个固定频率的输出。

更可能出现的情况是：学习模块覆盖更多环节，但快速控制、安全约束和系统监控仍然保留。分层边界会变化，不一定会消失——它正在从「人写死的模块接口」变成「模型内部的两级频率」。[《VLA 模型如何实现实时且平滑的动作控制？》](https://zhuanlan.zhihu.com/p/1986820879024427514) — CLEAR Lab · 🔵（3.2 已出现）里讲的快慢系统就是这个变化的具体形态：低频负责语义与任务，高频负责动作生成与实时修正，两者之间不再是人工设计的接口。

### 4.4 先追求通用，还是先做到可靠？

会一百项任务但每项偶尔成功，和稳定做好五项任务，代表两种不同目标。学术研究更关心新任务、新环境和新本体上的泛化，产业落地则要求可预测、可维护，也要知道失败的边界在哪里。第一章并读的两篇——[《具身智能需要从 ImageNet 做起吗？》](https://zhuanlan.zhihu.com/p/1906157729292219201) — 许华哲Harry · 🟢（1 章已出现）与 [《具身智能：一场需要谦逊与耐心的科学远征》](https://zhuanlan.zhihu.com/p/1906835485990565345) — 周指导BoyuZhou · 🟢（1 章已出现）——在这个问题上的侧重明显不同，回头对照会更有启发。

以后的重要进展，未必只是机器人又学会一个动作，也可能是它知道自己什么时候不会，能在出错前停下，并在需要时向人求助。

## 五、想继续往前走，可以从哪条路径进入？

前面四章把领域和问题铺完了，这一章会给四条进入路径。每条都标了先修与大致投入，可按自己的背景进行选择。

这一章的引用大多是前面章节已经推荐过的内容，放在这里是为了给出阅读顺序，章末表格标注了它们首次出现的位置，想看完整推荐语可回到对应章节。

### 5.1 想先建立全局认识

**先修**：机器学习基础概念。**投入**：约一周。

并读 [《具身智能需要从 ImageNet 做起吗？》](https://zhuanlan.zhihu.com/p/1906157729292219201) — 许华哲Harry · 🟢 与 [《具身智能：一场需要谦逊与耐心的科学远征》](https://zhuanlan.zhihu.com/p/1906835485990565345) — 周指导BoyuZhou · 🟢，对照规模化学习与机器人长期积累两种视角。随后精读 [《具身 VLA 的 2025：从 Demo 到通用的距离》](https://zhuanlan.zhihu.com/p/1989799567177307432) — 林天威 · 🔵，把数据、模型、真机训练和评测连起来。若还有余力，[《机器人具身智能三大流派：强化学习、VLA、World Model 到底在争什么？》](https://zhuanlan.zhihu.com/p/2013539588820444796) — 机器人技术笔记 · 🟢 可作名词速查。

### 5.2 想理解 VLA 与世界模型

**先修**：Transformer、注意力机制。**投入**：两到三周。

从 [《【综述】具身智能中的 VLA 模型》](https://zhuanlan.zhihu.com/p/1951985172259004422) · 🟢 建立基础，用 [《【VLA系列】万字深度解析 π0》](https://zhuanlan.zhihu.com/p/1907535034941965833) — AIming · 🔵 看一个具体模型的内部，再通过 [《Diffusion Policy——基于扩散模型的机器人动作生成策略》](https://zhuanlan.zhihu.com/p/670555655) — 王建明 · 🟢（2.1 已出现）补齐动作生成这一端。最后读 [《Fast-WAM：关于 WAM 核心能力来源的思考》](https://zhuanlan.zhihu.com/p/2018464228785275484) — 清华MARS Lab · 🔵（2.3 已出现），练习分析世界模型的能力来源。

需要深入生成式动作模型的数学基础时，可把 [《从第一性原理理解 Diffusion & Flow Matching（SDE、ODE 的大一统视角）》](https://zhuanlan.zhihu.com/p/2070555284918080338) — 妖妖 · 🟣 作为进阶材料。它不是具身智能入门必读，更适合已经学过概率、微积分和常微分方程的同学。

### 5.3 想做控制与强化学习

**先修**：本系列第二册《RL 蓝宝书》的第二章，或等价的 RL 基础。**投入**：一个月以上（含动手）。

先读 [《机器人强化学习与关节 PD 控制》](https://zhuanlan.zhihu.com/p/1990213475369255309) — 白告 · 🟣，理解策略和执行器之间的接口；再用 [《RL 做足式机器人运控的经典必读文章（带私货）》](https://zhuanlan.zhihu.com/p/29806809248) — Eric Liu · 🔵 建立研究地图。路线规划可以参考 [《具身智能（运动控制方向）如何学习？》](https://www.zhihu.com/question/2019488603890266175/answer/2022307874802517337) — 林博 · 🟢。想动手跑起来，[《四足、轮腿、人形开源项目（我跑过的）》](https://zhuanlan.zhihu.com/p/708902030) — youyouhuang826 · 🟣 给了一批可直接复现的开源项目。有控制基础后，再按需选读 [《人形机器人运动控制 Know-How》](https://zhuanlan.zhihu.com/p/1993986785630499920) — Jagger · 🟣。

想继续追踪机器人 RL 的新组合，可以参考 [《2026 年 RL（强化学习）在 Robotics（具身智能）中的新范式分析》](https://zhuanlan.zhihu.com/p/2002328291592401820) — gurubar · 🔵。这是年度盘点和前瞻判断，时效性较强，信息密度也高，适合用作选题索引，但不适合作为初学者的第一篇教材。

### 5.4 想找研究选题或进入实验室

> [!WARNING]
> 本节及 5.3 末尾引用的《2026 RL 新范式》《CoRL 2025》《2025 Robotics Top 10》均为年度盘点类内容，到下一年即需复审替换，阅读时注意发布时间。

**先修**：读完前面任意一条路径。**投入**：持续。

可以从一个具体的闭环切入：怎样低成本采集包含失败恢复的数据？动作块如何兼顾连贯与及时反馈？世界模型应该预测像素、状态还是任务相关的潜变量？怎样用有限真机试错稳定提升策略？评测如何同时衡量泛化、恢复与安全？

[《【机器人顶会 CoRL 2025 best paper 完整分析】从 π0.5 到 LocoFormer》](https://zhuanlan.zhihu.com/p/1955201866083315851) — gurubar · 🔵 与 [《2025 年 Robotics（具身智能）最值得推荐阅读的 10 篇顶会 Paper（总结）》](https://zhuanlan.zhihu.com/p/1998052390599950753) — gurubar · 🔵 覆盖了数据系统、感知、策略、控制和安全等方向，适合用来发现选题。两篇都是年度盘点，时效性强，也更接近研究索引而不是教程——找到感兴趣的工作后，建议回到原论文和项目页面核对。

读论文或项目报告时，可以固定检查六件事：

1. 任务怎样定义？
2. 数据来自哪里？
3. 动作怎样表示？
4. 反馈如何获得？
5. 测试时改变了什么？
6. 失败案例是什么？

模型名字一直会变，这六个问题却能帮我们判断，一项工作究竟解决了具身智能链条中的哪一环。

以后再看到新的 VLA、世界模型或机器人 Demo，可以先用第二章那四个问题定位它在解哪一环，再用这六个问题检查它的证据。具身智能的方法还会快速更新，但「会动—会做事—持续把事情做成」这条尺度不会很快就过时。

## 📖 术语速查

| 术语 | 含义 |
|-|-|
| 具身智能 | 研究智能如何从与物理环境的持续交互中产生的视角 |
| 遥操作 | 由人直接操控机器人完成任务，用于采集示范数据 |
| 行为克隆 | 模仿学习的基本形式：给定状态，监督学习示范者的动作 |
| 分布漂移 | 策略在测试时进入训练数据未覆盖的状态，预测误差被进一步放大并持续偏离 |
| 动作分块 | 一次预测未来若干步的一段动作，减少有效决策次数 |
| Diffusion Policy | 用扩散模型对动作分布建模并采样，可表达多峰动作 |
| Flow Matching | 与扩散同类的连续生成方法，直接学习从噪声到动作的向量场 |
| 多峰动作分布 | 同一状态下存在多种同样合理的动作 |
| VLA | 视觉—语言—动作模型，输入图像与指令，输出机器人动作 |
| 动作表示 | 动作用离散 token 还是连续向量表达，是 VLA 绕不开的分歧之一 |
| 动作专家 | VLA 中专门负责生成动作的子模块，常采用扩散或 flow 结构 |
| 跨本体 | 不同机器人的关节、相机、控制频率不同导致的数据与模型迁移问题 |
| 世界模型 | 预测环境如何随动作变化的模型，用于规划或表征学习 |
| 特权信息 | 仿真中可见、真机上不可得的量（如精确摩擦系数），常用于教师—学生训练 |
| 域随机化 | 在仿真中随机化物理参数，使策略对参数误差不敏感 |
| 系统辨识 | 用真机数据估计仿真参数，缩小仿真与现实的差距 |
| 教师—学生训练 | 教师用特权信息训练，学生只用可观测输入模仿教师 |
| Sim-to-Real | 仿真训练、真机部署，以及两者之间的差距问题 |
| 奖励稀疏 | 多数任务只有成功/失败的二值反馈，缺少中间信号 |
| MPC | 模型预测控制：每个控制周期求解一个有限时域优化问题，只执行第一步，下一周期重新求解 |
| WBC | 全身控制：统一求解人形机器人各关节力矩的优化方法 |
| PD 控制 | 比例—微分控制，最常用的关节级跟踪控制器 |
| 快慢系统 | 低频做语义规划、高频做动作执行的双层结构 |
| 轨迹拼接 | 相邻动作块的衔接处理，处理不好会造成抖动 |
| 安全降级 | 网络或算力异常时机器人切换到保守但仍安全的行为 |
